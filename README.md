## 🚀 How to Run & Preview Locally

Since this version uses pure web standards without external build dependencies, you can preview it immediately with Python:

```bash
# In the portfolio-v2 folder:
py -m http.server 8000
```

Then open `http://localhost:8000` in your web browser.

---

## 🌐 Deploying to GitHub Pages

1. Create or select a repository on GitHub (e.g. `mostafaeltaweel-portfolio`).
2. Push the contents of `portfolio-v2/` to the `main` branch.
3. In GitHub Repository **Settings $\to$ Pages**, set the source branch to **`main` / (root)**.
4. Your portfolio will be live worldwide in seconds!
